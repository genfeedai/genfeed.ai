# Support

## Where to get help

**GitHub Discussions** is our primary and only community support channel:

- Questions: https://github.com/genfeedai/genfeed.ai/discussions/categories/q-a
- Ideas & feature requests: https://github.com/genfeedai/genfeed.ai/discussions/categories/ideas
- Show and tell: https://github.com/genfeedai/genfeed.ai/discussions/categories/show-and-tell

We deliberately do **not** run a Discord, Slack, or forum. Discussions keeps answers searchable and public.

## Contributing

Looking to contribute? Start with a [`good first issue`](https://github.com/genfeedai/genfeed.ai/labels/good%20first%20issue) or a [`help wanted`](https://github.com/genfeedai/genfeed.ai/labels/help%20wanted) issue. See [CONTRIBUTING.md](CONTRIBUTING.md) for the 15-minute first PR path and the bounty flow.

## Bugs

Open a [bug report](https://github.com/genfeedai/genfeed.ai/issues/new?template=bug.yml). Please include a minimal reproduction that does not depend on private infrastructure.

## Security

Do not open public issues for security vulnerabilities. See [SECURITY.md](SECURITY.md).

## Commercial support

For commercial support, contact the maintainers via the email listed in [GOVERNANCE.md](GOVERNANCE.md).
