## Contributing

We welcome contributions of all sizes. **New here? Start with a [`good first issue`](https://github.com/genfeedai/genfeed.ai/labels/good%20first%20issue)** — each one is small, self-contained, and reproducible without private infrastructure.

- **Community & questions:** [GitHub Discussions](https://github.com/genfeedai/genfeed.ai/discussions) — this is our only community channel (no Discord/Slack/forum).
- **Bounties:** some issues carry [Algora](https://algora.io) bounties. Comment `/attempt` on the issue to claim one.
- **Full guide:** see [CONTRIBUTING.md](CONTRIBUTING.md), including the [15-minute first PR path](CONTRIBUTING.md#your-first-pr-in-15-minutes).
