## Contributing

We welcome contributions of all sizes — from a one-line docs fix to a new backend feature.

- 🚀 **New here?** Start with a [`good first issue`](https://github.com/genfeedai/genfeed.ai/labels/good%20first%20issue) — each one is small, self-contained, and includes a local verification step. You can make your first PR in ~15 minutes without the full dev stack.
- 💬 **Questions or ideas?** Join the conversation in [GitHub Discussions](https://github.com/genfeedai/genfeed.ai/discussions) — our only community channel (no Discord/Slack/forum).
- 💰 **Bounties:** Some issues are funded via [Algora](https://algora.io/genfeedai). Look for the `bounty` label.
- 📖 **Full guide:** See [CONTRIBUTING.md](CONTRIBUTING.md) for the dev setup, PR contract, CLA, and label guide.
