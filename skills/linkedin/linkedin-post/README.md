# LinkedIn Post

Write a LinkedIn text post: story, insight, contrarian, listicle, celebration or objection-based thought leadership.

## Installation

```bash
bunx skills add genfeedai/skills --skill linkedin-post
```

## Usage

```
"Write a LinkedIn post about what I learned hiring my first ten people"
"Turn this sales objection into a thought leadership post"
```

## What It Does

- Six proven post formats with structures
- Hook patterns and a never-use list
- Tone calibration and comment strategy
- First-comment link and hashtag guidance
