# LinkedIn Article

Write a LinkedIn article or newsletter edition with a hook, sections, action steps and a promo post.

## Installation

```bash
bunx skills add genfeedai/skills --skill linkedin-article
```

## Usage

```
"Write a LinkedIn article on how we cut our reporting time in half"
"Draft this week's LinkedIn newsletter edition"
```

## What It Does

- Article template with word budgets
- SEO and distribution guidance
- Newsletter edition structure
- Promo post and first comment
