# LinkedIn Carousel

Plan and write a LinkedIn carousel (PDF document post) with slide copy, a design spec and a caption.

## Installation

```bash
bunx skills add genfeedai/skills --skill linkedin-carousel
```

## Usage

```
"Make a LinkedIn carousel from this framework"
"Turn my article into a 10-slide LinkedIn carousel"
```

## What It Does

- Slide-by-slide outline and copy
- Design rules and topic frameworks
- Caption and first-comment plan
- Hands the spec to carousel-renderer when installed
