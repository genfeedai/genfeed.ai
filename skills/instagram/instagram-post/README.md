# Instagram Post

Write an Instagram feed post: caption, hashtags, alt text and the image brief.

## Installation

```bash
bunx skills add genfeedai/skills --skill instagram-post
```

## Usage

```
"Write an Instagram caption for this product photo"
"Build a hashtag set for a fitness coach"
```

## What It Does

- Hooks that land inside 125 characters
- Body patterns and CTAs
- Tiered hashtag method
- Alt text and image brief
