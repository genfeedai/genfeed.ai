# Instagram Carousel

Plan and write an Instagram carousel: slide copy, design spec, caption and handoff to a local renderer.

## Installation

```bash
bunx skills add genfeedai/skills --skill instagram-carousel
```

## Usage

```
"Create an Instagram carousel on 7 pricing mistakes"
"Turn this blog post into a 10-slide carousel"
```

## What It Does

- 10-slide structure and slide copy rules
- Topic formulas by niche
- Caption and hashtag handoff
- Hands the spec to carousel-renderer when installed
