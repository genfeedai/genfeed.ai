# Instagram Reel

Write an Instagram Reel: hook, timed script with text overlays, caption and production handoff.

## Installation

```bash
bunx skills add genfeedai/skills --skill instagram-reel
```

## Usage

```
"Write a 20-second Reel script on onboarding mistakes"
"Give me three Reel hooks for a bakery launch"
```

## What It Does

- Eight hook types with text overlays
- Timed script template
- Optimization and audio direction
- Production handoff to video skills
