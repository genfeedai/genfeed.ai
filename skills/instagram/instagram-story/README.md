# Instagram Story

Write an Instagram Story sequence with stickers, a CTA and a weekly theme calendar.

## Installation

```bash
bunx skills add genfeedai/skills --skill instagram-story
```

## Usage

```
"Plan a 6-frame Story sequence for our launch"
"Write a Q&A Story sequence with a question box"
```

## What It Does

- 5 to 7 frame arc
- Sticker strategy
- Weekly theme calendar
- Safe-area and design notes
