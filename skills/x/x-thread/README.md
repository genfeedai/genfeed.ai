# X Thread

Write an X (Twitter) thread of 2 to 15 posts with a hook, a value chain and a closing CTA.

## Installation

```bash
bunx skills add genfeedai/skills --skill x-thread
```

## Usage

```
"Create a 10-part thread on lessons learned building a startup"
"Turn this blog post into an X thread"
```

## What It Does

- Builds the hook, value chain and closing CTA
- Enforces one idea per post and standalone posts
- Adds pinned TL;DR and bump post plans
- Returns numbered posts ready to paste
