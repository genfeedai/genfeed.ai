# X Article

Write a long-form X Article and the promo post that sends the timeline to it.

## Installation

```bash
bunx skills add genfeedai/skills --skill x-article
```

## Usage

```
"Write an X Article on why content calendars fail"
"Turn this blog post into an X Article with two promo posts"
```

## What It Does

- Structures a titled long-form piece with claim headings
- Writes the title, header image brief and pull quotes
- Writes two promo posts that work without the link
- Marks unsourced claims and unverified format limits
