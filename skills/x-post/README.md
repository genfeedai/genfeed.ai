# X Post

Write a single X (Twitter) post, quote post or reply: hooks, the 280-character edit, algorithm signals and a checklist.

## Installation

```bash
bunx skills add genfeedai/skills --skill x-post
```

## Usage

```
"Write a tweet about the future of AI in healthcare"
"Draft a quote tweet adding a contrarian take on this post"
"Write a reply that adds value to this conversation"
```

## What It Does

- Writes single posts with proven hook formulas and CTAs
- Drafts quote posts that add context, data or a contrarian view
- Designs reply tactics for visibility and relationships
- Applies X algorithm signals, timing and viral patterns
- Ends with a pre-post checklist
