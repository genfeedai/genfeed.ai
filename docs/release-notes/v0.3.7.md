**New**
- Reverse engineer a reference: in a storyboard plan, "..." then "Reverse a video" (a Library video up to 60 s) turns its takes into shots with timed cuts, camera moves, sound and a prompt per shot, and "Reverse an image" adds its look as the style and one shot that recreates it. The storyboard agent tool has the same `reverse` action. Cut times are estimates read from sampled frames.
- Every place that asks which account to post to shows the same avatar row, the profile picture with its platform badge: the agent publish and schedule cards, the platform pickers that used to show text only, and the Filters menus.
- Channel logos sit on square tiles, so the connected accounts on MCP channel cards line up.
- Operator alerts (trend ingestion health, Apify budget) go to their own Discord Alerts channel instead of the posts channel. Set the channel ID in Admin > Platform settings > Notifications; until then those alerts are skipped.
- The agent and every app with a conversation beside its output get a drag handle between them, with one remembered width, and full size puts the thread list on the left.
- The Playground uses the same layout, conversation on the left and output on the right. The Context panel no longer reopens itself, and no longer stays stuck after its record is removed.
- The Agent prompt bar no longer has the Auto/Manual/Plan mode dropdown or the prompt-enhancement popover; it shows the + button and Send or the microphone.
- The post editor's AI actions are one Improve menu (Shorten, Simplify, Boost, Hashtags, Optimize caption, Make Thread on X, and the tone) next to Ask agent. The duplicate Add first comment, End with @grok and the credit quote are gone from that row.
- ElevenLabs speech, voice clones, deletes and alignment run only on the organization's own ElevenLabs key. An ElevenLabs voice with no connected key is refused with "Connect your ElevenLabs account in Settings > Integrations" before any credit is held. HeyGen billing is unchanged.
- Emails show a video as its first frame with a play button, and the card title stays on one line.
- MCP `upload_media` takes a `brandId`, so an upload lands in the brand you name. An organization with several brands must name one.
- HeyGen Video 1 is available through fal as a video model.
- New models in the catalog: Gemini Omni Flash 1.2 (video, replaces the old Omni endpoint, cost and label), P-Video 2 Pro (video), and MAI-Image-2.7 and 2.7 Flash (images on fal, four rows). Studio's edit picker lists MAI-Image-2.7 Edit and 2.7 Flash Edit; the default edit model and Auto routing are unchanged.

**Better**
- Pickers in the prompt bar (folder, quality, resolution, aspect ratio, outputs, avatar, voice, duration, preset, brand voice, elements) and the scope and status pickers share one select with an icon per option and a search field.
- Credit pack tiles name their credits.
- One copy button, and every copy goes through the same clipboard service, so each copy shows the same feedback.
- Workflow editor nodes use the same buttons, inputs, selects and switches as the rest of the app.
- Image and video prompt enhancement knows more lens, color grade and light terms.
- The Turbo landing paints its starter cards at once, and agent ideas are kept for 30 minutes per brand.
- Success and warning button variants, so agent cards, the review inbox and brand-kit setup use the shared button and sizes. Approve and publish keep their green look; a few buttons are 32 px tall now.
- Wan 3.0 on Replicate costs about 30% fewer credits, following Replicate's current price (117 credits for 5 s).
- Coming-soon entries and unavailable connect tiles are hidden instead of shown disabled.
- Dates in the app, the extension and agent cards read the same short date everywhere.
- The @ and ! mention popups in agent chat share one list, with the keyboard-selected row styled the same everywhere.
- The public profile shows each total once, in its tab label, instead of repeating it in the header, beside section titles and under the lists.
- The rich text editor toolbar uses the shared toggle, so bold, italic, strikethrough, code, lists, blockquote and code block show their pressed state.
- The article traffic panel uses the shared date range picker, with a start and end date (up to 366 days, 30 days by default) and today's partial day included. The API takes `startDate` and `endDate` instead of `period`.
- A stand-alone X post is no longer cut at 280 characters when it is generated, so a long argument post comes out whole. Posts in a thread stay at 280.
- Workspace dashboard links, the clipper back links and Generate button, the folders sidebar and the task toolbar use the shared button variants and sizes. Clipper back links are the foreground colour, and the clipper Generate button is the large size.

**Fixed**
- An organization that was given admin credits is no longer held back by the free trial, so it can generate right away.
- A generated draft keeps its line breaks in the post editor instead of running its sentences together.
- Analytics collection runs for every organization with a published post, on its schedule (every 30 minutes for due posts), not only for those with a recent session. X posting credits still limit what X returns.
- Drafts the agent writes are tied to the brand's only connected account on that platform, so the post page shows the profile picture instead of a gray platform letter. A data migration does the same for existing drafts that have no account.
- Switching organization is handled in one place, and the provisional state while an organization is confirmed no longer leaks into requests.
- A video whose stored file the retention sweep deleted no longer gets a signed link to it, so the Posts list does not show a 403.
- MCP `get_assets` lists the CDN link of every uploaded image beside its URL, so uploaded images get a signed link instead of none.
- The approvals inbox shows a play button and mounts a video only when it is played, to keep the tab light.
- Reverse, mirror and text overlay on a video queue their completion event like resize, so an API restart no longer leaves the video processing.

**Steadier**
- The API logs one JSON line per entry in production, which is cheaper per request. The short request stalls are still being traced; this is a mitigation, not a proven fix.
- The API task runs at 2 vCPU and 4 GB instead of 1 vCPU and 2 GB, to test whether the 1 vCPU quota causes the request stalls. It is reverted if stalled requests per day do not fall by at least half after the deploy.
- The app stops error replay recording and reports DOM growth when a tab passes 768 MiB, to find the approvals page crash. Also a mitigation, not a proven fix.
