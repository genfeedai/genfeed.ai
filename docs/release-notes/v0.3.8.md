**New**
- Instagram Reels can carry music: under "Reel only" in the post flow, "Add music" searches Instagram's audio catalogue (trending when the search is blank) and sets the music and Reel sound volumes. Agents search the catalogue with `check_channel(action=music)`. A track Instagram refuses fails the publish instead of posting a silent Reel. Whether the music may be used for brand or commercial posts is not confirmed.
- Instagram Stories: pick "Story" in the post composer for one image or one video. A Story sends no caption and no alt text, and a post with more than one media item is refused before Instagram is called.
- A Library image can be the cover of an Instagram Reel (set `coverImageId` through the agent or MCP). If Instagram refuses the cover, the Reel is published without it.
- Images carry alt text (up to 1,000 characters), written in the Library under Info. Instagram receives it with the post, slide by slide in a carousel.
- `gf asset upload <path...> [--folder <id>] [--json]` uploads local files to the Library from the command line.
- Posting to X works for any organization that holds credits, on the free plan too. An X post that the wallet cannot pay for (3 credits, 30 with a link) is refused right away with a link to buy credits, instead of failing quietly later.
- TikTok and YouTube posts carry the AI-generated disclosure by default (TikTok "Creator labeled as AI-generated", YouTube "Altered or synthetic content"). A per-target setting in the post settings turns it off. If TikTok refuses the labelled request, the post is sent again without the label.
- TikTok Inbox posts show "Delivered" on their receipt, a failed target shows its reason in a tooltip on the badge, and retrying a TikTok video asks whether to send it to the Inbox or post directly. A post that cannot be opened shows a not-found or load-error screen with "Back to posts" and "Try again".
- The Brand Kit has a Visual direction field (up to 2,000 characters). Image and video prompts read it; text posts never do. Writing voice shows a Text budget meter, so a kit that is too long to approve says so before Approve is pressed.
- Branded image requests that attached nothing now get the brand's style and product references. References are named by role in the prompt and fill the model's slots subject and product first, then composition, then style, for Nano Banana, FLUX 2, SeeDream and the other image models. Studio shows these references as chips you can remove; removing all of them sends none, and the generation receipt says how many were added.
- The approved palette is measured on the stored pixels of a branded image or video, and the report is saved on the generation receipt.
- Over MCP, an agent can set a brand's name and approve its Brand Kit.
- Skills are marked web or desktop, and desktop skills run in the Desktop terminal session.
- An Apps menu in the topbar.
- The brand profile header is redesigned and has a Public analytics setting.
- A super admin can attach a dedicated instance to an organization, and the organization's own text models can run on it. A missing or stopped instance answers 503 and never falls back to a hosted model.
- The privacy page now says who receives Google data and how long it is kept.

**Better**
- A general agent chat turn sends 18 core tools plus `find_tools` instead of all 148 tool definitions: about 185 KB down to 36 KB per request. Other tools load through `find_tools` or on first call by name.
- The app shell is flush: the rail, page menu and context panel run the full window height, with a centered breadcrumb. On Desktop the window controls sit over the rail.
- Daily publishing caps follow what the organization has paid: an organization that never paid can publish 1 post per day per connected account, one that bought credits up to 5 on each platform, and one on a plan up to 25 on X, 15 on Instagram, 10 on YouTube and 10 on TikTok. The owner sets the cap with a slider, and the saved value comes back when a plan is bought.
- The Calendar side panel shows the real images of a post, has a Settings view with an "Edit caption and media" button, and calendar chips start with the account avatar and tint to the platform colour. Cancelled posts are hidden unless the Status filter includes them.
- Account avatars with a platform badge have a round outline instead of a square one.
- An expired trial can spend the credits it earned, and refunds stay earned. An agent tool that bills credits holds its price before it runs, so two concurrent calls on a balance that pays for one start only one.
- The free YouTube tools share a global daily spend cap beside the per-IP limit, refuse sources over one hour before downloading, and run the clipper highlight pass on the cheaper model.
- Depleted X credits, duplicate X posts, Instagram rejections and refused scheduled publishes are recorded as known outcomes instead of being retried or reported as faults. A TikTok post keeps its Inbox delivery through retry and scheduled recovery.
- A Threads account records the scopes it granted when it connects.
- Onboarding, the OAuth consent page and the agent claim page render their shell on the server, and more destinations are prepared as you point at them.
- The Desktop app shell is back under 150 MiB, leaves `/admin` out, and serves its service worker source map from the packaged app.

**Fixed**
- Voice cloning always uses ElevenLabs. The Genfeed AI clone option, its provider choice and the fleet voice-clone webhook are gone; a request for it answers 400.
- A Redis error no longer makes every organization route answer 403: the request context is built from the database when the cache fails. The shared Redis client, the queue producer connection and the health-check client reconnect after a cache node switch instead of staying closed until a restart, and `/health` answers 503 when a Redis client is closed for good so the task is replaced.
- Publishing an article publishes only the revision that passed the reader-copy check.
- A super admin's `?organizationId=` override no longer makes Brand OS revision writes fail.
- A winner batch is kept when a brand promotion is denied, and a denied workflow actor now logs which check refused it.
- A Brand Kit whose required text is over the generation budget can no longer be approved, with a message naming the longest fields.
- First-run images on Nano Banana 2.1 no longer fail with "Pricing is unavailable": the request now carries the model's default resolution tier, so the price quote matches a reviewed rate.
- The public profile lists posts newest first by publish date.
- A closed trend incident is no longer reported as a recovery, and the purge, retention and checkpoint jobs stay inside the database transaction budget.

**Steadier**
- API keys: write routes now name the scope they need. A key that used to pass on any one write scope must hold the named one. Web-only write routes, account and integration routes, admin and organization management, post generation, remix and analytics, brand generation and edit, Library assets, workflows, personas, clipper projects, tasks, the Messages inbox, Skills and content performance are affected. Routes the CLI, MCP server and Desktop call keep their scopes, and signed-in web sessions are unaffected.
- The self-hosted LLM route and the shared GPU media client are removed, so text and media run only on hosted providers or an organization's own dedicated instance. The two `local/` chat models are retired: a stored reference to one asks for a new model to be picked, and is never sent to a provider.
- A database migration adds `alt_text` to Library images (additive, empty for every existing image).
- Dependencies are current: vitest 5.1.2, NestJS 12.6.2, Stripe SDK 23.2 (API version pinned to 2026-11-18.endive), ui-sdk beta.17 and @xyflow/react 13. Patched copies of body-parser, undici, vite, node-forge, effect and sharp.
