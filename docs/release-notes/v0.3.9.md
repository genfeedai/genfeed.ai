**New**
- Library assets keep a version history: each asset shows its versions, which one is active, and a Restore action that makes an older version active again.
- The Library has an Elements API and a References page for the images a brand reuses.
- Ad presets check the spoken dialogue against the script after the video is generated.
- A post in the Posts list shows its real media and the account it goes to.
- Public brand reach totals include followers.
- Message replies carry an idempotency key per attempt, so a retried reply cannot be sent twice.
- MCP approval requests have Approve and Decline buttons.
- A YouTube upload from the composer carries the AI-generated label.
- Discovery plays TikTok and Instagram trend videos in Genfeed's own player.
- The workflow editor has grouped node controls and an annotation and trajectory editor, and a workflow can run motion control through the funded media pipeline.
- A super admin can refresh the platform skills from `genfeedai/skills` over the admin API, and the CLI can sync the free presets and skills into the store from the pinned `genfeedai/catalog` and skills catalogs.
- Instagram posts are prepared before they are due: the media container is created in the minutes before the scheduled time, so a carousel goes out within seconds of its slot instead of after a long upload.
- A cancelled post can be reopened in place, as a draft or rescheduled, and the Posts list shows each post once.
- Connect lists every AI client in one place with its setup steps, in the app and on the MCP setup page, and Grok is added.
- Desktop has a settings page with the workspace folder and a check of the editing tools (ffmpeg, Bun and the rest), keeps workspace folders open in cloud mode, and runs a local CLI turn on the model you chose.
- Workspace owners can see and stop member subscriptions.
- A brand can choose which Google Ads account it connects.
- A Dev.to article can be saved as a draft from the target setting.
- Social accounts on the profile open in their own app on a phone.

**Better**
- The Connect dialog shows compact platform cards.
- The Profile tabs switch in place instead of loading a new page.
- One bar sits under the topbar, with two columns and a multi-select in threads. The menu strip and the Desktop title row are aligned, and the dotted background is gone.
- Tables show a faded preview with a description and a call to action when they are empty; the same faded preview is used on the no-brand page and on card grids.
- Text fields show focus through their border. Overview charts keep their height.
- Posts show one activity row each.
- Claude clients are pointed at the full-access MCP URL, and the setup no longer tells Claude Code to install a plugin.
- The Discord post card shows a plain-text caption and the account handle.
- The custom credit amount field is polished, the Context toggle is hidden when a page has no selection, and the store addresses point at shop.genfeed.ai.

**Fixed**
- A paid scrape that returns nothing now pauses the source and raises an alert. Each Apify source is bought once per refresh, and scrapers that returned nothing are removed.
- Niche TikTok search runs only after the Trends read.
- A refused winner promotion logs which check refused it.
- The marketing card for the Library page renders again.
- A dev.to article is sent with its canonical URL and series when they are set.
- A first comment added to an existing release is queued, and a draft release's comment posts are scheduled together with their target post.
- A media upload from an agent asks for a brand when the organization has several, instead of filing the asset under whichever brand was opened last.
- Reference images of a character granted to your brand preview again, and the activity feed shows only the brands a member can access.
- MCP generation tools get a 55 s budget instead of 30 s, and parallel tool calls share their identity and organization lookups.

**Steadier**
- API keys: more routes name the scope they need (the 0.3.8 change continues across the remaining route families). Managing API keys with an API key requires the admin scope. Public routes are skipped by the scope ratchet.
- A check fails a pull request that changes a package under a version that is already published, and the stale npm packages are bumped.
- The skills catalog is pinned to a reviewed `genfeedai/skills` commit.
- Every Apify run is logged with its caller.
- Desktop local mode is deleted, together with the API's desktop sync endpoint. Desktop runs against the cloud API only.
- The single-pack checkout in Skills Pro is removed; the store sells the one bundle.
- Dependencies are current again, including NestJS 12.6.3, Sentry 11.19 and the AWS SDK 3.1178.
- The publish sweeps run on their own queue.
- Admin skill refresh shows what a refresh would change per skill, never overwrites an edited skill without a decision, and a live run needs the full commit SHA.
- The shared MCP policy primitives (roles, access modes, mutation policy, credit pricing, the 30-tool cap) live in one package, `@genfeedai/mcp-kit`, instead of several copies.
- The API boots under its heap budget again, so the release gate can pass.
- The sign-up captcha and font origins are added to the report-only Content-Security-Policy before it is enforced.
- The release workflow stages every npm package in a run and names the ones npm holds for approval.
