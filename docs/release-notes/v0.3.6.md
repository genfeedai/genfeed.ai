**New**
- Facebook is a real channel now: connect a Facebook Page, publish a photo or video to it, and go live on it. Page comments and Messenger conversations arrive in Messages and you can answer them as the Page (Messenger replies work inside Meta's 24 hour window). Reconnect Facebook once to grant the new permissions.
- Threads replies arrive in Messages, and Instagram hashtag trends now come from Instagram's official hashtag search.
- Delete a published post from the post page, the list or a bulk selection. On X and Mastodon you can delete the network copy too; elsewhere the post stays live and you remove it there. MCP and the CLI can delete a post and its Library media after a confirmation.
- The review inbox lists questions your agent is waiting on, alerts you, and lets you answer from the row. A workflow can start a content agent run from a trigger event.
- Put a post in a campaign from its drawer, and see impressions on the campaign Performance tab.
- Public profiles have a new header with one tab per content type.
- One account picker, an avatar row with the platform badge, in the post modal and the release rail.
- MCP `track_link` now works without naming a brand in the call.
- Recap and ready-to-publish emails show real media previews, an audio waveform and one-line stats.

**Faster**
- A reload paints your rail and the last data from the device while the workspace is checked, and signing out shows the sign-in page at once.
- Streamed agent replies no longer re-render every message, and the Home connection line paints from its last confirmed state.

**Safer and steadier**
- Credits are held before text generation and content evaluation run, and pending generation approvals stay uncharged.
- Stopping an agent run, or cancelling a running generation, now cancels it at the provider so it stops billing.
- Videos finish through a durable queue, so a restart no longer strands a finished clip.
- Every API request waits while a routed organization is still being confirmed, so nothing is read for the wrong organization.
- Switching organization keeps the shell on screen, and a refused organization or an ended session clears everything stored on the device.
- Sign-in codes are exchanged in one step, workflow badges follow the last run to finish, and private media previews in workflows refresh on their own.
- Every dialog keeps its title and buttons in view and scrolls only its body; form choices are option tiles, and dates read the same everywhere.
- The app reports a tab that is running out of memory so the cause can be found.
