## What shipped (this branch)

**Flat panels (decision 1).** Shell wrapper padding and inter-region gaps removed; regions are flush and square; both sidebars now read the same way.

**Inspector rail parity with the left sidebar** (Vincent, live): collapsed width is `0`, not a 48px stub — a visible rail is exactly what he did not want. Same surface (`bg-background`), same motion as `DesktopSidebar` (300ms `cubic-bezier(0.32, 0.72, 0, 1)` on **both** `width` and `min-width`), `border-l` conditional on open state or a 1px line survives at width 0. The two in-panel collapse/expand Buttons are gone; the single toggle is pinned in the topbar.

- New: [WorkspaceInspectorContext.tsx](../../apps/app/src/components/workspace-shell/WorkspaceInspectorContext.tsx). Needed because `AppProtectedTopbar` is a *prop* of `AppLayout` while `UniversalWorkspaceShell` is its *child* — siblings, so the shared open state has to be provided above both. `useWorkspaceInspector()` returns `null` with no provider, so the shell still renders standalone (unit tests) defaulting to expanded.
- "Pushes the content" was already satisfied: `--workspace-inspector-width` is published by the shell and consumed at `xl:` by the topbar shell, content shell, and rail. It just needed the collapsed value to become `0`.

**Floating composer (decision 5 / Vincent, live).** The "black box below the prompt bar" was the docked flex row reserving opaque space. The composer slot is now `absolute inset-x-0 bottom-0` inside the (already `relative`) region column, `pointer-events-none` on the frame + `pointer-events-auto` on the portal target so the gap either side stays scrollable. Content scrolls *under* it: canvas gained `pb-28 md:pb-32` (graph canvas excluded — it owns its own viewport); the conversation list already had `pb-56 md:pb-72`. The outer lift went on the composer's own surface (`AgentChatInput`'s `PromptBarShell`), not `PromptBarContainer` — that container is positioning-only by design — via new `shadow-composer` / `shadow-composer-strong` utilities following the existing `shadow-dropdown`/`shadow-dialog` idiom.

**Overview density (decision 2) + empty-state soup + Credits dedupe (decision 5).**

- Stats strip is 3 items in `DashboardGrid cols={3}` (new `3` variant). Credits removed — the topbar already carries the live balance.
- Empty brand collapses to one `workspace-dashboard-first-run` block. The predicate is exported as `hasWorkspaceOverviewSignal()` and reused by `workspace-page.tsx` to hide the task queue *and* the overview sidebar on the same condition — two definitions would let the guided block render with the empty bands it replaces stacked underneath. **Loading counts as signal**, so a returning operator never sees a flash of first-run copy.
- e2e-safe: `playwright/e2e/fixtures/api-mocks.fixture.ts:1236` seeds two tasks, so `workspace.spec.ts:84-96` (all five sidebar cards) still passes.
