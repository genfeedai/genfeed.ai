The maintainer clarified that `/agent` should explain Genfeed's own agent,
including its capabilities, examples, review, and publishing behavior.

**Why:** Sending a connection CTA through the Genfeed agent page and then a
client-specific marketing page adds unnecessary steps before setup.

**How to apply:** `Connect your agent` is an action that opens setup on the
current page. Let visitors choose their client and immediately access its real
install command, connector destination, or connection prompt. When the current
page already identifies the client, open its setup directly. Keep detailed
client pages available as documentation and search destinations. Account
creation, sign-in, and consent belong in the actual Genfeed authentication flow;
do not claim the connection succeeded before it has been verified.
