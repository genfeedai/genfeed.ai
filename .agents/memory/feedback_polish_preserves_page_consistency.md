Polish existing product pages by matching their surrounding pages and shared UI components.

**Why:** The user rejected the admin user detail page's separate profile-style layout because it looked different from the rest of the admin app. Visual consistency takes priority over an isolated polished treatment.

**How to apply:** Compare at least three nearby examples. Reuse the existing page shell, toolbar action placement, content width, cards, typography and metadata conventions. Improve spacing and legibility within that structure.
