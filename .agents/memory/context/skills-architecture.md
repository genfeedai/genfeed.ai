# Skills Architecture — Genfeed.ai

**last_verified: 2026-07-26**

Three directories, one constraint: **no external symlinks, no paths outside the monorepo.**
Clone and go.

| dir | contents | git |
|---|---|---|
| `skills/` | product/content skills the app ships (31) | committed, real files |
| `.agents/skills/` | dev/build skills for working on the app (47) | committed, real files |
| `.claude/skills/` | symlinks to `../../.agents/skills/<name>` only | gitignored, generated |

- `.claude/skills/` is regenerated by `scripts/setup-skills.sh`, run from `postinstall` on `bun install`.
- Curate dev-skill syncs — never bulk-import an external skill repo.
- `codebase-health.yml` validates skill integrity weekly in CI.
