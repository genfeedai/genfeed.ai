**Rule:** Use a normal link styled as a button for Book a call. Do not embed a scheduling iframe on the Done for you page.

**Why:** The embedded calendar disrupts the marketing layout and adds an unnecessary booking surface. The user explicitly requested a direct link.

**How to apply:** Resolve the destination from the shared website booking data. The existing booking section may remain as explanatory copy with a link button, but must not load an iframe or report a button click as a confirmed booking.
