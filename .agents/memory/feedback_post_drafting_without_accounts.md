---
name: Direct post drafting without accounts
description: Writing and generating drafts remain available without connected publishing accounts; agent assistance is optional
type: feedback
last_verified: 2026-09-24
---

Users can manually write or generate a social post, including a tweet, without connecting the destination account. Keep direct creation accessible in Publishing; the agent is an optional assistant, not the only entry point. Require a connected account when scheduling or publishing.

**Why:** Account readiness is a delivery constraint, not an authoring prerequisite. Selected workspace context should not appear as instructions in a visible starter prompt.

**How to apply:** Send the selected brand as structured request context and validate its organization access server-side. Keep visible prompts short. See #5042 for implementation evidence.
