# Better Auth user IDs are opaque

`users.id` is the canonical user reference, but production contains legacy
Better Auth base62 IDs alongside UUIDs generated by the current auth factory.

**Why:** Treating an authenticated `userId` as a Genfeed entity ID rejects valid
legacy accounts before their active organization membership can be checked.

**How to apply:** Treat authenticated user IDs as non-empty opaque strings. Use
membership and ownership queries for authorization. Keep `isEntityId` for
Genfeed-owned entity IDs, not for Better Auth user/session/account identifiers.
