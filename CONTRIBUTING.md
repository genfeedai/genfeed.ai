## Code of conduct

By participating you agree to our [Code of Conduct](./CODE_OF_CONDUCT.md).
Please report unacceptable behaviour to the maintainers listed in
[GOVERNANCE.md](./GOVERNANCE.md).

## Ways to contribute

You do not need to write code to help. We welcome:

- Documentation fixes and new guides.
- Bug reports with a minimal reproduction.
- Triaging issues and answering questions in Discussions.
- UI polish, accessibility fixes and copy edits.
- Small backend fixes with a clear test.

## Community

**GitHub Discussions is our only community channel.** We deliberately do not run a
Discord, Slack or forum — everything happens in the open on GitHub so it is
searchable and permanent.

- 💬 [Ask a question / start a discussion](https://github.com/genfeedai/genfeed.ai/discussions)
- 🐛 [Report a bug](https://github.com/genfeedai/genfeed.ai/issues/new?template=bug.yml)
- 💡 [Request a feature](https://github.com/genfeedai/genfeed.ai/issues/new?template=feature.yml)
- 🙋 [Pick up a task](https://github.com/genfeedai/genfeed.ai/issues/new?template=task.yml)

If you are unsure where to start, open a Discussion and a maintainer will point
you at something that fits your interests.
