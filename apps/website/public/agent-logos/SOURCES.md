# Agent application marks

These assets are unmodified copies from first-party application sites, retrieved
on 2026-10-02. Serve them locally so setup cards do not depend on third-party
image requests. Application names remain the accessible link labels; the marks
are decorative.

Products in the same family share their provider's official mark. The hosted
Codex page at https://chatgpt.com/codex serves the same OpenAI favicon as ChatGPT.
Meta Muse uses Meta's corporate mark; this is not a custom Muse logo.

The OpenAI SVG follows its embedding document's color scheme. The logo container
uses a light color scheme and white background so every original mark remains
legible in either site theme without changing its colors or shape.
