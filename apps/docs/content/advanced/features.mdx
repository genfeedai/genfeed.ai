# Advanced Surfaces

Genfeed's source tree includes workflow orchestration, webhooks, realtime
events, publishing integrations, analytics modules, agent tools, and extension
clients. Availability depends on your release and on the provider credentials
you configure.

## Verify before relying on a surface

1. Confirm the module or client exists in the release you run.
2. Confirm the route or workflow node is registered on your instance.
3. Confirm required provider credentials and approvals.
4. Run a focused end-to-end check for the path you intend to operate.

## Boundaries

- The self-hosted image is a single-tenant web/API/MCP Docker distribution.
- Execution uses your own provider keys; there are no Genfeed credits.
- Desktop is macOS-first. Mobile and extension workspaces do not imply public
  store listings.

No SOC 2, GDPR, encryption, SSO/SAML, support, or SLA claim should be inferred
from the presence of source code. You are responsible for the security of your
deployment; see [Reverse Proxy and HTTPS](/self-host/reverse-proxy).
