# Getting Started

Choose the distribution that matches the work you want to do.

## Genfeed Cloud

The hosted product is available at [app.genfeed.ai](https://app.genfeed.ai).
Cloud account setup, plan availability, and managed-service entitlements can
change independently of this repository. Use the hosted product UI and current
pricing pages as the source of truth for those details.

## Community self-hosting

Community is the public, single-tenant Docker distribution. It runs the web app,
REST API, MCP server, PostgreSQL, and embedded Redis without requiring local
Node.js, Bun, or a Genfeed Cloud account.

Follow the [self-host quick start](/guides/self-host-quickstart). Add a provider
key only when you want generation; the application can boot without one.

## Source development

Contributors need Node.js 24, the latest stable Bun from `.bun-version`, Git, and Docker Compose for local
PostgreSQL/Redis. Use the repository's canonical
[contribution guide](https://github.com/genfeedai/genfeed.ai/blob/master/CONTRIBUTING.md)
instead of the distribution quick start.

## CLI

The published CLI can be installed with Bun:

```bash
bun add --global @genfeedai/cli
genfeed --help
```

See the [CLI reference](/api-reference/cli) for authentication, configuration,
and the full command surface.

## API access

Programmatic access uses a `gf_` API key created in organization settings at
`/{orgSlug}/~/settings/api-keys`. The same key authenticates the REST API and the
hosted MCP server:

```bash
export GENFEED_API_KEY=gf_live_xxx
curl https://api.genfeed.ai/v1/posts \
  -H "Authorization: Bearer $GENFEED_API_KEY"
```

Follow the [API keys guide](/api-reference/api-keys) for scopes, rate limits, and
rotation. In managed cloud, API access is a paid-plan entitlement; self-hosted
deployments always have it.
