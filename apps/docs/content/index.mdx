# Genfeed Documentation

**Genfeed is an open-source AI OS for content creation, and you run it yourself.**

It combines a visual workflow system, provider-backed generation, brand and
content management, and programmatic interfaces (REST API, MCP server, CLI, and
webhooks) in one self-hosted instance. You bring your own model provider keys,
your data stays on your infrastructure, and an agent can drive it end to end.

Don't want to host it? Use Genfeed Cloud at [genfeed.ai](https://genfeed.ai).

## Start here

1. **[Check the system requirements](/self-host/system-requirements).** About 8 GB
   of free disk, Docker Compose v2, and ports 3000, 3010, and 3014.
2. **[Install it](/self-host/installation).** Run `npx @genfeedai/create my-genfeed`,
   or use the checksummed release bundle with Docker Compose. No clone needed.
3. **[Add your provider keys](/self-host/provider-api-keys).** OpenAI, Anthropic,
   Replicate, fal, and ElevenLabs. Self-hosting has no Genfeed credits.
4. **[Follow the first steps](/self-host/after-it-is-running).** Connect MCP at
   `localhost:3014`, point the CLI at your API, and ship a first post.
