# MCP Server

Use the hosted Genfeed MCP server to give your agent permission-scoped access to content, workflows, publishing, analytics, and ads.

**Endpoint:** `https://mcp.genfeed.ai/mcp`

**Transport:** Streamable HTTP.

**Default authentication:** browser OAuth; no manually created API key.

Open the [guided Connect Genfeed flow](https://app.genfeed.ai/connect) to choose
your client and authorize access. The page supplies setup instructions; your
client owns sign-in, consent, and the resulting access token.

## Connect via OAuth

Add Genfeed using the instructions below, complete sign-in and consent in your
browser, and return to your client. Genfeed advertises its authorization server
through `/.well-known/oauth-protected-resource`.

### Claude Code

```bash
claude mcp add --transport http genfeed --scope user https://mcp.genfeed.ai/mcp
```

Open `/mcp` inside Claude Code, select `genfeed`, and authenticate. Follow the
browser sign-in and consent flow, then return to Claude Code.

### Codex

```bash
codex mcp add genfeed --url https://mcp.genfeed.ai/mcp
```

If authorization did not open during setup, run:

```bash
codex mcp login genfeed
```

Alternatively, add this to your user-level `~/.codex/config.toml` and run the
login command above:

```toml
[mcp_servers.genfeed]
url = "https://mcp.genfeed.ai/mcp"
```

### Other MCP clients

In a client that supports remote Streamable HTTP and OAuth, add the endpoint as
a custom MCP server and follow its browser authorization flow. Installation and
availability depend on the client and your plan. If OAuth is unsupported, update
your client or use the advanced manual-key setup below. No application deep link
is required.

### Verify access

Ask your agent: **“List my Genfeed brands.”** A successful scoped read verifies
access. `codex mcp list` or `claude mcp list` can diagnose configuration, but a
server entry or copied command alone does not prove authorization. The Genfeed
setup page cannot observe a third-party client's OAuth completion.

If consent is denied or the login expires, restart authorization through
`codex mcp login genfeed` or Claude Code's `/mcp`. Check the account and organization
on the consent screen. Revoke unwanted access from Genfeed's API key settings.

Client syntax was checked against Codex CLI 0.153.2 (`mcp add --help` and
`mcp login --help`) and the [Claude Code MCP documentation](https://code.claude.com/docs/en/mcp).

## Advanced: manual API key

Use this for headless environments or clients without browser OAuth. Select
**Advanced: manual API key** in [Connect Genfeed](https://app.genfeed.ai/connect)
to create or select a scoped key and run the authenticated verification check.
Keys remain copy-once. See [API Keys](/api-reference/api-keys) for rotation and revocation.

In a Bash terminal where your client runs, enter the key without putting its
value in shell history:

```bash
read -s GENFEED_API_KEY && export GENFEED_API_KEY
```

Then choose your client:

```bash
claude mcp add --transport http genfeed --scope user https://mcp.genfeed.ai/mcp --header "Authorization: Bearer $GENFEED_API_KEY"
```

```bash
codex mcp add genfeed --url https://mcp.genfeed.ai/mcp --bearer-token-env-var GENFEED_API_KEY
```

The Claude command expands the key into client configuration; protect that local
configuration. Codex reads the named environment variable. Do not paste credentials
into chats, commits, or shared logs. Inspect and update an existing Genfeed server
entry before switching authentication methods; preserve unrelated servers.

## Tools

Each call uses the permissions on the authorized token or manual key.

- **Content and media:** articles, images, videos, music, avatars, batches.
- **Workflows:** list, create, execute, inspect status.
- **Publishing:** list and publish social posts.
- **Analytics and ads:** analytics, campaigns, Google Ads, Meta Ads.
- **Agents and admin:** threads, approvals, role-gated admin tools.

## Skills

MCP gives an agent Genfeed's tools; [Agent Skills](/skills) give it the content
knowledge to use them well. Install the catalog with
`bunx skills add genfeedai/skills`.

## HTTP Details

The endpoint accepts `POST`, `GET`, and `DELETE`. Authenticated requests include a token managed by the OAuth client or a manual key:

```http
Authorization: Bearer <access-token>
```

Missing, invalid, or expired tokens return 401 errors.

## Local Self-Hosted Surface

Self-hosted Genfeed uses `http://localhost:3014/mcp` when the MCP service is running. Cloud uses:

```text
https://mcp.genfeed.ai/mcp
```

## Troubleshooting

- **Discovery fails:** use exactly `https://mcp.genfeed.ai/mcp` and a Streamable HTTP client.
- **401 errors:** repeat browser authorization; in manual mode, check the key and its scopes.
- **Wrong endpoint:** check `/v1/config` on the MCP host.
