# Billing and Credits

Cloud billing, subscriptions, credit packs, and managed-inference usage are
commercial surfaces. Fixed prices and included credits are intentionally not
copied into these docs because they can change independently of a repository
release.

Use the [current pricing page](https://genfeed.ai/pricing) and the checkout UI as
the source of truth before purchasing.

## Repository boundary

- The entire repository, billing included, is AGPL-3.0-or-later. Organization
  billing code lives in the API at
  `apps/server/api/src/collections/{subscriptions,user-subscriptions,subscription-attributions}/`
  and ships in every image.
- Whether organization billing is live is decided at runtime by
  `hasOrganizationBilling()` — see
  [Billing: one build, a runtime gate](https://github.com/genfeedai/genfeed.ai/blob/master/docs/deployment-modes.md#billing-one-build-a-runtime-gate).
  Community self-hosts get no-op stubs and no billing routes, and do not sell
  managed credits locally.
- A Community or desktop client can use managed inference only through an
  explicit Cloud API key and Cloud-credit authorization.

This page does not promise a trial, fixed price, included quota, seat count,
support tier, or SLA.
