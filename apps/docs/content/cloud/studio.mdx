# Studio

Studio is the product workspace for prompt-driven generation. It combines model
selection, output settings, references, and supported brand context with the
configured generation providers.

Generated assets can appear in product library surfaces when the active flow
persists them. Available content types, models, dimensions, and actions depend
on the provider registry and deployed release.

These docs intentionally avoid undocumented keyboard shortcuts and do not claim
that every generated asset is automatically saved or publishable.

See [Available Models](/models) and [Brands](/cloud/brands).

## Edit an image

In **Studio → Generate**, select **Edit image**, add a source from Library or
upload an image, and describe the change. You can also choose **Edit image** on
a ready image in Library to open Studio with that image selected and an empty
instruction.

Ideogram 4.5 on Replicate is the default for editing. Editing sends your
instruction directly to the model. The original stays in Library; each result
is a separate image linked to its source.

- Add up to five source images. The target selector determines which image
  receives the edit; additional sources provide visual context.
- Optionally add one mask with the same dimensions as the target. Black areas
  can change and white areas stay. A mask uses the source dimensions.
- Choose source dimensions or a supported output size, one to eight outputs,
  and an optional integer seed. Editing uses medium quality.
- Choose **Edit image** on a result to start another edit using that result.
  **Reuse** restores the original instruction, sources, mask and seed. If an
  original input is unavailable, add the inputs again before submitting.

In Agent chat, attach or identify a Library image and ask for a specific change,
such as “Change the sign to OPEN.” The `edit_image` tool uses the same editing
workflow and saves its results to Library.

Organization model access still applies. Existing organizations with an explicit
model allowlist must enable Ideogram 4.5 for editing. Configure Replicate through
[AI Providers](/integrations/ai-providers); provider and credit availability
determine whether an edit can run.
